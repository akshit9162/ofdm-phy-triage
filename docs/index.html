Where it breaks

40% of failures still fail with the fault removed: the SNR was too low as well. The model never says both.

Run it

33 tests, including simulated BER against the closed-form Gray QAM curves.

  • Uncoded, single antenna, one packet; EVM is the only pass criterion.
  • Textbook impairment models, not measured hardware.
git clone https://github.com/akshit9162/ofdm-phy-triage
cd ofdm-phy-triage
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest -q
.venv/bin/python -m scripts.campaign 8000 runs/main 0
.venv/bin/python -m scripts.campaign 4000 runs/test 1
.venv/bin/python -m scripts.evaluate runs/main runs/test results
